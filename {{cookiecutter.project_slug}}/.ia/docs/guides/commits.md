# Diretrizes para Mensagens de Commit

1. **Idioma**: sempre em português do Brasil, claro e objetivo.
2. **Formato**: Conventional Commits — `tipo(escopo?): mensagem`
3. **Tom**: imperativo curto — `ajusta`, `adiciona`, `corrige`, `remove`, `refatora`
4. **Escopo**: nome do app ou módulo afetado quando relevante
5. **Corpo**: incluir o *porquê* quando a mudança não for óbvia pelo título
